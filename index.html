1.1 공구관리시스템이란

공구관리시스템은 인스타그램 인플루언서 공동구매(공구) 비즈니스의 전 과정을 하나의 웹앱에서 관리하는 시스템입니다. 구글 캘린더에 일정을 등록하면 자동으로 공구 워크플로우가 생성되고, 판매 입력부터 정산서 자동 생성, 카카오톡 메시지 템플릿까지 모든 업무를 처리할 수 있습니다.

이 시스템은 구글 Apps Script(GAS) 기반 웹앱으로 동작합니다. 별도의 서버 없이 구글 스프레드시트를 데이터베이스로 사용하며, 구글 캘린더·구글 드라이브와 연동됩니다.

1.3 주요 용어 정리

용어설명
공구인플루언서가 팔로워 대상으로 진행하는 공동구매. 일정 기간 동안 특정 제품을 할인가에 판매합니다.
셀러공구를 진행하는 인플루언서를 말합니다. 인플루언서와 동의어로 사용됩니다.
업체(제조사)공구 제품을 공급하는 업체입니다. 제조사 또는 벤더사(유통사)일 수 있습니다.
벤더(당사)우리 회사(UNDEFIANCE)를 의미합니다. 셀러와 업체 사이에서 중개 역할을 합니다.
결제창결제를 누가 관리하느냐에 따라 '제조사', '벤더사', '인플루언서' 3가지로 구분됩니다.
정산유형셀러의 세금 처리 방식. '사업자'(세금계산서), '현금영수증', '3.3%'(원천징수), '베벤더' 4종류입니다.
부가세구분업체의 부가세 처리 방식. '포함'(VAT 포함가)과 '별도'(VAT 별도가) 2종류입니다.
수수료방식수수료를 %(비율)로 계산하거나 '원'(정액/개당)으로 계산하는 방식입니다.
PG수수료스마트스토어, 네이버페이 등 결제 플랫폼에서 차감되는 수수료입니다.
워크플로우하나의 공구에 대한 전체 정보를 담는 레코드입니다. 캘린더 동기화 시 자동 생성됩니다.

⚙️ 시작하기 — 초기 설정

시스템을 처음 사용하기 위한 단계별 설정 가이드입니다.

2.1 구글 스프레드시트 준비

시스템의 모든 데이터는 하나의 구글 스프레드시트에 저장됩니다. 스프레드시트 ID는 URL에서 확인할 수 있습니다.

스프레드시트 URL 형식
https://docs.google.com/spreadsheets/d/여기가_스프레드시트_ID/edit
💡 시스템 초기화를 실행하면 필요한 모든 시트(업체마스터, 셀러마스터, 제품마스터, 정산워크플로우, 판매입력, 샘플관리, 카톡템플릿, 정산총괄, 공구매출현황, 매출목표)가 자동 생성됩니다.

2.2 구글 캘린더 연결

시스템은 복수의 구글 캘린더를 동시에 연동할 수 있습니다. Code.gs의 CONFIG.CALENDAR_IDS 배열에 사용할 캘린더 이메일 주소를 등록합니다.

Code.gs 설정 예시
CALENDAR_IDS: ['your@gmail.com', 'another@gmail.com']
⚠️ 캘린더 일정의 셀러명, 업체명, 제품명은 각 마스터 시트에 등록된 이름과 정확히 일치해야 자동 매칭됩니다. 오타나 띄어쓰기 차이가 있으면 매칭되지 않습니다.

2.3 구글 드라이브 폴더 구조

시스템은 두 개의 드라이브 폴더를 사용합니다.

📁 정산서 폴더 (SETTLEMENT_FOLDER_ID)
정산서 엑셀(.xlsx) 파일이 자동 저장되는 폴더입니다. NAS Cloud Sync와 연동하면 자동 백업됩니다.
📁 서류보관 폴더 (DOCUMENT_FOLDER_ID)
사업자등록증, 통장사본 등 서류를 보관하는 폴더입니다. 아래 구조로 만들어야 합니다.
서류보관 폴더 구조
서류보관폴더/
├── 업체/
│ ├── 뷰티솔루션/ ← 업체명과 동일한 폴더명
│ └── 헬스팜/
└── 셀러/
├── 홍길동/ ← 셀러명과 동일한 폴더명
└── 김영희/

2.4 시스템 초기화

1
웹앱 상단 메뉴에서 ⚙️ 설정 탭을 클릭합니다.
2
🔧 시스템 초기화 버튼을 클릭합니다.
3
확인 팝업에서 '확인'을 누르면, 필요한 모든 시트가 구글 스프레드시트에 자동 생성됩니다.
4
초기화 완료 후, 스프레드시트를 열어 각 마스터 시트에 데이터를 입력합니다.
⚠️ 시스템 초기화는 이미 존재하는 시트는 건너뛰므로, 기존 데이터가 삭제되지 않습니다. 안심하고 실행해도 됩니다.

2.5 웹앱 배포 및 접속

구글 Apps Script 편집기에서 배포 → 새 배포 → 웹 앱을 선택합니다. '액세스 권한이 있는 사용자'를 '나만' 또는 '조직 내 모든 사용자'로 설정한 후 배포합니다.

배포 후 생성된 URL로 접속하면 공구관리시스템 웹앱이 열립니다. 모바일 브라우저에서도 동일하게 사용할 수 있으며, 반응형 디자인이 적용되어 있습니다.

📋 마스터 데이터 등록

마스터 데이터는 시스템의 기반입니다. 반드시 캘린더 동기화 전에 먼저 등록하세요.

⚠️ 마스터 데이터 입력 순서: 업체마스터 → 셀러마스터 → 제품마스터. 캘린더 동기화 전에 완료해야 수수료율이 자동 매칭됩니다.

3.1 업체마스터

컬럼명필수설명 및 입력 방법
NO자동행 번호입니다. 직접 입력하거나 비워두셔도 됩니다.
업체명★ 필수캘린더 일정의 업체명과 정확히 일치해야 합니다.
결제창★ 필수드롭다운: '제조사', '벤더사', '인플루언서' 중 선택
수수료율(셀러)★ 필수셀러에게 지급할 수수료 비율(%). 숫자만 입력. 예: 15 → 15%
수수료율(벤더)★ 필수우리(벤더) 수수료 비율(%). 숫자만 입력. 예: 5 → 5%
부가세구분★ 필수드롭다운에서 '포함' 또는 '별도' 선택. 기본값은 '포함'.
수수료방식(셀러)선택드롭다운에서 '%' 또는 '원' 선택. 기본값은 '%'.
수수료방식(벤더)선택드롭다운에서 '%' 또는 '원' 선택. 기본값은 '%'.
담당자명선택업체 담당자 이름. 카톡 템플릿에서 자동 삽입됩니다.
연락처선택업체 연락처. 카톡 템플릿에서 자동 삽입됩니다.
사업자번호선택정산서에 자동 표시됩니다.
CS링크선택고객 문의 페이지 URL. 카톡 템플릿에서 사용됩니다.

결제창 유형 이해

🏭 제조사 (10단계)
업체가 직접 결제를 받고, 우리에게 수수료를 지급합니다.
🏢 벤더사 (8단계)
우리(벤더)가 결제를 받고, 업체에 정산금을 지급합니다.
👤 인플루언서 (6단계)
셀러가 직접 결제를 받고, 업체에 정산금을 지급합니다.

수수료율 계산 예시

💡 수수료율(셀러) = 15, 수수료율(벤더) = 5인 경우:
총매출 100만원 → 셀러마진 15만원, 벤더마진 5만원, 업체정산금 80만원

3.2 셀러마스터

컬럼명필수설명 및 입력 방법
셀러명★ 필수캘린더 일정과 정확히 일치해야 합니다.
정산유형★ 필수드롭다운: 사업자 / 현금영수증 / 3.3% / 베벤더
인스타그램선택@아이디 또는 URL. 카톡 템플릿에서 자동 삽입됩니다.
연락처선택전화번호. 샘플 발송 카톡에서 자동 삽입됩니다.
주소선택샘플 수령 주소. 카톡 템플릿에서 자동 삽입됩니다.
수령인명선택택배 수령인명. 셀러명과 다를 수 있습니다(매니저 등).
사업자번호선택사업자인 경우 입력. 정산서에 표시됩니다.

정산유형 상세 설명

🏢 사업자
세금계산서를 발행받아 정산. 가장 일반적인 유형.
🧾 현금영수증
현금영수증을 발행하여 정산. 사업자등록은 있으나 세금계산서가 어려운 경우.
📉 3.3% 원천징수
프리랜서 원천징수. 정산금에서 3.3% 차감 후 지급. 홈 화면에 세무용 내역 자동 집계.
🏪 베벤더
벤더사 형태의 셀러. 정산서 탭 이름이 '인플루언서' 대신 '베벤더'로 표시.

3.3 제품마스터

컬럼명필수설명 및 입력 방법
업체명★ 필수업체마스터의 '업체명'과 정확히 동일하게 입력해야 합니다.
제품명★ 필수캘린더 일정의 제품명과 정확히 일치해야 합니다.
공구가★ 필수소비자 판매가격. 숫자만 입력. 예: 29900
모델옵션선택옵션, 용량, 색상 등. 예: 30ml, 레몬맛, 블랙
공급가선택업체에서 받는 원가. 숫자만 입력(쉼표 없이). 예: 15000
수수료율(셀러/벤더)선택비워두면 업체마스터 값을 사용합니다. 제품별 다를 때만 입력.
💡 하나의 업체에 여러 제품이 있을 때, 제품마다 수수료율을 다르게 설정할 수 있습니다. 판매입력 화면에서도 품목별로 수정 가능합니다.

3.4 서류보관 폴더 → 마스터 자동등록

서류보관 폴더(DOCUMENT_FOLDER_ID)에 '업체' 또는 '셀러' 하위 폴더를 만들면, 캘린더 동기화 시 해당 폴더명이 마스터 시트에 자동 등록됩니다.

📅 캘린더 동기화

구글 캘린더 일정을 등록하고 동기화하면 공구 워크플로우가 자동 생성됩니다.

4.1 캘린더 일정 작성 규칙

📌 형식: 셀러명-업체명-제품명

예시:
· 홍길동-뷰티솔루션-비타민C 세럼
· 김영희-헬스팜-프로바이오틱스
· 박민수-푸드마켓-닭가슴살 세트
⚠️ 하이픈(-)이 3개 부분(셀러-업체-제품)을 구분하는 역할을 합니다. 제품명에 하이픈이 포함된 경우 자동으로 처리됩니다(첫 번째 하이픈 = 셀러/업체 구분, 두 번째 이후 = 제품명에 포함).

4.2 동기화 실행

1
웹앱 홈 화면에서 🔄 캘린더&폴더 동기화 버튼을 클릭합니다.
2
확인 팝업에서 '확인'을 누릅니다.
3
동기화 완료 후 결과 알림 확인:
· 📋 공구 일정: 총 N개 (신규 N, 업데이트 N)
· 🚫 제외된 일정: N개
· 📁 마스터 등록: 업체 N개, 셀러 N개 신규 등록

4.3 자동 매칭 원리

1

3
셀러마스터에서 셀러명이 일치하는 행을 찾아 정산유형, 인스타그램, 주소 등을 가져옵니다.
4
제품마스터에서 업체명+제품명이 일치하는 행을 찾아 품목별 수수료율을 가져옵니다.
5
이 정보를 결합하여 정산워크플로우 시트에 하나의 행을 생성합니다.

7.3 마진 자동계산 원리

💰 마진 계산 공식
소계 = 공구가 × 판매수량
셀러마진 = 소계 × 셀러%
벤더총수익 = 소계 × 벤더%
벤더마진 = 벤더총수익 - (PG수수료 + 배송비 + 기타비용)
업체정산금 = 총매출 - 셀러마진 - 벤더총수익 - 비용합계

7.4 비용 입력

  • PG수수료: 스마트스토어, 네이버페이 등 결제 플랫폼 수수료
  • 배송비: 배송 관련 비용
  • 기타비용: 기타 발생 비용
💡 이 비용들은 내부 손익계산용이며, 외부 정산서에는 표시되지 않습니다.

7.5 부가세 별도 계산기

업체마스터에서 부가세구분이 '별도'로 설정된 업체의 공구를 선택하면, 🧾 부가세 별도 업체 체크박스가 자동으로 체크되고 계산기가 활성화됩니다.

  • 업체정산금(공급가액): 총매출 - 셀러마진 - 벤더마진 - 비용
  • 부가세(10%): 공급가액 × 10%
  • 업체 실지급액(VAT포함): 공급가액 + 부가세
  • 벤더순마진(VAT차감): 벤더마진 - 부가세

❓ 자주 묻는 질문 (FAQ)

Q. 캘린더 동기화했는데 수수료율이 0으로 나옵니다. ▼
업체마스터에 해당 업체가 등록되어 있지 않거나, 캘린더 일정의 업체명과 업체마스터의 업체명이 정확히 일치하지 않는 경우입니다. 업체마스터에서 이름을 확인하고 재동기화하세요. 또는 스프레드시트의 정산워크플로우 시트에서 직접 수수료율을 입력해도 됩니다.
Q. 판매입력 시 '제품이 등록되어 있지 않습니다'가 표시됩니다. ▼
제품마스터에 해당 업체의 제품이 없는 것입니다. 제품마스터의 '업체명' 컬럼에 업체마스터와 동일한 이름으로, '제품명' 컬럼에 캘린더 일정과 동일한 이름으로 제품을 등록하세요.
Q. 정산서에 서류첨부 탭이 없습니다. ▼
서류보관 폴더에 해당 업체/셀러 폴더가 없거나 폴더 내에 이미지 파일이 없는 경우입니다. 드라이브에 이미지를 업로드한 후 정산서를 재생성하세요.
Q. 정산완료를 되돌리고 싶습니다. ▼
공구매출 탭에서 해당 공구의 상태 옆 ↩ 버튼을 클릭하거나, 정산 체크리스트에서 해당 공구를 클릭한 후 상세 패널의 '정산완료 되돌리기' 버튼을 클릭하세요.
Q. 카톡 템플릿의 변수가 치환되지 않습니다. ▼
공구를 선택해야 변수가 치환됩니다. 또한 일부 변수({{오늘판매}}, {{송장번호}} 등)는 자동 치환이 불가하여 직접 수정해야 합니다.
Q. 부가세 별도 업체인데 계산기가 활성화되지 않습니다. ▼
업체마스터에서 부가세구분이 '별도'로 설정되어 있는지 확인하세요. 설정 후 캘린더 동기화를 다시 실행해야 워크플로우에 반영됩니다.
Q. 여러 사람이 동시에 사용할 수 있나요? ▼
구글 스프레드시트는 동시 편집을 지원합니다. 다만 웹앱에서 동일한 공구를 동시에 수정하면 나중에 저장한 데이터가 이전 데이터를 덮어쓸 수 있으니 주의하세요. Apps Script 배포 시 "액세스 권한"을 "조직 내 모든 사용자"로 설정하면 팀원 모두 사용 가능합니다.
Q. 공구매출현황 시트의 서식이 깨졌습니다. ▼
공구매출 탭에서 '📄 구글시트 동기화' 버튼을 클릭하면 시트가 삭제 후 재생성되면서 서식이 초기화됩니다.

⚠️ 웹앱 접속 시 흰 화면만 표시됨
  • Apps Script 편집기에서 배포가 정상적으로 되었는지 확인합니다.
  • 브라우저의 개발자 도구(F12) → Console 탭에서 오류 메시지를 확인합니다.
  • 스프레드시트 ID가 올바른지 확인합니다.
⚠️ '대시보드 로드 실패' 오류
  • 구글 스프레드시트에 접근 권한이 있는지 확인합니다.
  • 정산워크플로우 시트가 존재하는지 확인합니다. 없으면 시스템 초기화를 실행하세요.
  • 시트의 헤더행(1행)이 삭제되지 않았는지 확인합니다.
⚠️ 캘린더 동기화 시 0건 표시
  • CONFIG.CALENDAR_IDS의 이메일 주소가 올바른지 확인합니다.
  • 해당 캘린더에 접근 권한이 있는지 확인합니다(공유 캘린더인 경우).
  • 캘린더 일정의 날짜가 2026년 1월 1일 이후인지 확인합니다.
  • 일정 제목에 하이픈(-)이 포함되어 있는지 확인합니다.
⚠️ 정산서 생성 실패
  • 해당 공구에 판매 데이터가 있는지 확인합니다(총매출 > 0).
  • 구글 드라이브의 정산서 폴더(SETTLEMENT_FOLDER_ID)에 쓰기 권한이 있는지 확인합니다.
  • Google Apps Script 일일 실행 쿼터가 초과되지 않았는지 확인합니다.
⚠️ 마진 계산이 맞지 않음
  • 업체마스터의 수수료율이 올바른지 확인합니다 (예: 15 = 15%, 0.15가 아님).
  • 수수료방식이 '%'인지 '원'인지 확인합니다.
  • 부가세구분이 '별도'인 경우, VAT 제외 금액 기준으로 수수료가 계산됩니다.
  • 판매입력 시 품목별 수수료율을 직접 수정한 경우, 해당 값이 적용됩니다.
⚠️ 카톡 템플릿이 로드되지 않음
  • 카톡템플릿 시트가 존재하는지 확인합니다. 없으면 시스템에 내장된 기본 72개 템플릿이 사용됩니다.
  • 시트가 있으나 데이터가 없는 경우, 시트를 삭제하면 기본 템플릿이 로드됩니다.
